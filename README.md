\# Weather Station Using Arduino



\## Project Description

This project is an IoT-based Weather Station that monitors temperature and humidity using sensors.



\## Components Used

\- Arduino

\- DHT11 Temperature and Humidity Sensor

\- LCD Display

\- Connecting Wires



\## Working

The DHT11 sensor measures temperature and humidity. The collected data is displayed on the LCD screen.
